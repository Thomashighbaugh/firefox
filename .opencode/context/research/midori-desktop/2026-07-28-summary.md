# Midori Browser (goastian/midori-desktop)

**Note:** The primary development repository lives at [gitlab.com/midori-web/midori-desktop](https://gitlab.com/midori-web/midori-desktop); the GitHub mirror is `goastian/midori-desktop`.

## What it is

A lightweight, fast, privacy-focused Firefox fork by Astian, Inc. Features include:

- Workspaces
- Built-in search engine
- Custom new-tab page
- Ad blocker
- Cross-platform: Windows (10+), macOS (10.12+), Linux (Debian/Ubuntu/Mint, Arch/Manjaro)

## Installation

**Linux (Debian):**
```bash
sudo wget -O /etc/apt/trusted.gpg.d/midori-archive-keyring.gpg http://repo.astian.org/midori-archive-keyring.gpg
echo "deb http://repo.astian.org midori main" | sudo tee /etc/apt/sources.list.d/midori.list
sudo apt update
sudo apt install ./midori_<version>_amd64.deb
```

## Build pipeline

Midori uses **[Amelia](https://github.com/goastian/amelia)** (`@goastian/amelia`) as its build tool — a TypeScript wrapper around Mozilla's `mach` commands that automates source fetching, branding patches, and multi-platform packaging.

## Relevance to Firefox userChrome theme work

- A real-world consumer of Firefox userChrome customization patterns.
- The theme directory layout (`userChrome.css` + modular `CSS/` + `JS/` `.uc.js` scripts) is identical to the Higgs Boson theme conventions.
- Their `browser/extensions/` packaging path is how theme scripts would be shipped inside a Midori build.
