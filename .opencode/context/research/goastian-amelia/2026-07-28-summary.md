# Amelia — Simplifying building Midori Browser

**Status:** Prerelease / prototype phase.

## Overview

Amelia is a build tool for [Midori Browser](https://github.com/goastian/midori-desktop). It automates fetching Firefox source, applying Midori branding and patches, and packaging the result for multiple platforms. Published as `@goastian/amelia` on npm.

## Installation

```bash
npm install @goastian/amelia
```

## Usage

| Command              | Purpose                                                                          |
| -------------------- | -------------------------------------------------------------------------------- |
| `npm run self`       | Normal local run — builds Midori using current branch / patches.                  |
| `npm run self:ci-safe` | CI-safe run — also sets `AMELIA_SKIP_ADDON_GIT_INIT=1` and `CI=true`. Skips addon git commit. |

CI environment variables for accurate target-aware behavior:

```
AMELIA_PLATFORM=linux
AMELIA_COMPAT=aarch64
```

## CI-safe packaging and addons

Recent enhancements to the build pipeline:

- **Packaging preflight** — runs a Tor preflight check before `mach package`. Skipped on `linux-aarch64` and `win32-aarch64` (Tor unsupported).
- **Explicit aborts** — `mach package` and `mach package-multi-locale` now abort explicitly if they fail (no silent pass).
- **Addon git init** — skipped when `AMELIA_SKIP_ADDON_GIT_INIT=1` or `CI=true`.
- **mozbuild resolution** — addon mozbuild updates now look for `browser/extensions/moz.build` first, then fall back to `browser/extensions/app.mozbuild`, and create a base file if neither exists.
- **Branding fallback** — branding patch falls back to `browser/branding/official` when `browser/branding/unofficial` is missing.

## Provenance / lineage

Amelia is a fork of:

1. **[Surfer](https://github.com/zen-browser/surfer)** — Zen Browser's build tool.
2. **[Gluon](https://github.com/pulse-browser/gluon)** — extracted from melon; the build tool for the desktop version of [Dot Browser](https://github.com/dothq/browser-desktop). Gluon's author stopped working on it.
3. **[melon](https://github.com/dothq/browser-desktop)** — the original Dot Browser build tool.

## Relevance to Firefox userChrome theme work

- Demonstrates the modern Firefox fork / build pipeline (mach, mozbuild, branding layers).
- The `patches.sh` pattern shows how branding and feature patches are layered over an upstream Firefox tree.
- Useful reference if the Higgs Boson theme ever needs to be packaged as a Midori-flavored build or distributed through a fork's `browser/extensions/` path.
