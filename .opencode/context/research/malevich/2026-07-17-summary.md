# Malevich — Minimalist Firefox Theme

- **Source:** [hermitm0nk/malevich](https://github.com/hermitm0nk/malevich)
- **License:** MIT
- **Stars:** 4
- **Language:** CSS (58.5%), JavaScript (41.5%)

A dark Firefox userChrome.css theme — minimalistic, lightweight, and radically clean. Inspired by [Shyfox](https://github.com/Naezr/ShyFox).

## Core Philosophy

Every UI panel is hidden by default, leaving nothing but your content. Panels reveal themselves only when you hover the top or left edge of the window.

## Key Features

- **Vertical tab bar** on the left (native Firefox vertical tabs, FF136+)
- **Modern sidebar** (History, Bookmarks, etc.) on the right
- **Auto-hide navigation** — tab bar and navbar hidden by default, shown on hover
- **Toggle visibility** via Ctrl+Alt+Z or Toggle sidebar button
  - **Compact mode** (default) — auto-hide, show on hover
  - **Full mode** — always visible

## Requirements

- Firefox 136+ (native vertical tabs support)
- `toolkit.legacyUserProfileCustomizations.stylesheets = true`

## Key Preferences

```js
user_pref("sidebar.revamp", true);
user_pref("sidebar.visibility", "expand-on-hover");
user_pref("sidebar.position_start", true);
user_pref("browser.sidebar.moveOnResize", false);
user_pref("browser.tabs.allowAnimationPreference", false);
user_pref("browser.tabs.animate", false);
```

## CSS Module Structure

```
chrome/
├── userChrome.css          # Main entry point — imports all modules
├── userContent.css         # Website-level dark theme overrides
└── zen-modules/
    ├── _variables.css       # Design tokens, colors, spacing
    ├── _base.css            # Base reset and global styles
    ├── _bookmark-bar.css    # Bookmark bar styling
    ├── _vertical-tabs.css   # Vertical tab layout
    ├── _navbar-autohide.css # Navbar auto-hide behavior
    ├── _sidebar-separator.css # Sidebar separator styling
    ├── _urlbar.css          # URL bar styling
    ├── _content-frame.css   # Content area adjustments
    └── _dark-ui.css         # Additional dark UI overrides
```

## Relevance to This Project

Malevich shares several design patterns with the Higgs Boson Firefox Theme:

- Both are Firefox userChrome.css themes targeting the same customization layer
- Both use auto-hide/show-on-hover patterns for UI panels
- Both leverage native Firefox vertical tabs (FF136+)
- Malevich's modular CSS architecture (variables → base → components) mirrors this project's `css/chrome/` modular approach
- Malevich's sidebar-on-right approach contrasts with this project's second sidebar system (which operates on the left)

Notable differences:
- **Scale:** Malevich is smaller (9 CSS modules, no JavaScript); this project is 311 files, extensive JS, and a full second sidebar subsystem
- **FF version range:** Malevich targets FF136+ only; this project supports a wider Firefox range
- **Complexity:** Malevich is a pure CSS theme; this project adds userChrome.js scripts, XUL components, and web panels
- **Organization:** Malevich uses `zen-modules/` prefix; this project uses `css/chrome/`, `css/content/`, `css/common/`

## Potential Takeaways for Higgs Boson

1. The `_navbar-autohide.css` approach could inform or simplify the existing auto-hide behavior
2. The minimalistic design philosophy may inspire simplification of certain UI elements
3. The sidebar-on-right pattern is a deliberate contrast worth studying for users who prefer that layout
