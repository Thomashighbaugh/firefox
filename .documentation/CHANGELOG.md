## Changes

- **2026-10-11 17:12** [CSS/Content] about:addons: fixed the addon/theme card preview image width. Firefox 157 added `max-width: var(--page-main-content-width)` on `.card-heading-image` (author origin), overriding the theme's `max-width: calc(100% + 36px)`; added `!important`. Also audited all 156→157 built-in `about:*` and browser chrome stylesheet changes against the theme's selectors — no class/id renames, no other unguarded overrides found

- **2026-10-11 16:11** [CSS/Content] about:addons: restored the grid layout. Firefox 157 added an author-origin rule `#main > addon-list > section { display: flex; flex-direction: column }` to its built-in `aboutaddons.css`, which outranks our user-origin `display: grid` (author-normal beats user-normal in the cascade) and collapsed the extension list back to a single vertical column. Added `!important` to the section's `display: grid`

- **2026-10-11 03:53** [JS/about:config] Added a per-row selection checkbox to the about:config multi-select tool (a narrow first column on every pref row; the "add new pref" row gets an empty cell so the fixed table layout stays aligned). Selection is now tracked by pref name rather than row element, so it survives the table being rebuilt when the search filter changes; the checkboxes, row highlight, Ctrl/Cmd-click, Shift-click, Ctrl+C and the "Copy as user_pref()" button all stay in sync. The selection is cleared when the search filter changes

- **2026-10-11 01:32** [JS/about:config] Fixed the "no multiselect" about:config feature (corrected diagnosis). `about:config` is a privileged internal page that the **parent process** displays (Firefox process model: "treated as a content process with a null remote type") — it is **not** `privilegedabout`. It still could not be injected by fx-autoconfig because it loads inside a tab's `<browser>`, not a top-level window, so the loader (which only observes `domwindowopened`) never sees it. The previous `@include about:config*` attempt and the intermediate self-registered `privilegedabout` WindowActor were both wrong and were removed. `AboutConfigMultipleSelection.uc.js` is now a normal `@include main` browser-window script that watches for about:config tabs with `gBrowser.addTabsProgressListener` and installs the multi-select UI directly on the real document via `<browser>.contentDocument` (accessible because the page is parent-process). Adds Ctrl/Cmd-click and Shift-click multi-select, Ctrl+C, and a toolbar "Copy as user_pref()" button

- **2026-10-10 23:37** [JS/about:config] (superseded by the entry above) First attempts at the about:config multiselect fix

- **2026-10-10 21:55** [JS] Audited all userChrome.js scripts against the fx-autoconfig v0.10.15 API (which dropped the legacy `_uc`/`_ucPref`/`xPref` symbols) and Firefox 157. Removed dead scripts `rebuild_userChrome.uc.js` (old `_uc` API) and `newTabUrlInAboutConfig.uc.js` (`xPref` API). Rewrote three scripts: `AboutConfigMultipleSelection.uc.js` (first attempt used `@include about:config*`; superseded — see the later entry, about:config is out-of-process), `pdfTools.uc.js` (now `@include resource://pdf.js/web/viewer.html*` and uses the `PDFViewerApplication` API; the old `==UserChromeJS==` header was never parsed), and `allTabsMenuExpansionPack.uc.js` (eval-free rewrite targeting `gTabsPanel`/`TabsPanel` in `moz-src:///browser/components/tabbrowser/TabsList.sys.mjs`; keeps reverse-order + pending/pinned/container marking and drops the `toSource()`+`eval()` internal patches now handled natively). Added `// ==UserScript==` headers to `restart_button.uc.js`, `restart_item_in_menu.uc.js`, `space_and_separator_restorer.uc.js` (the first also gets `@onlyonce`); fixed `quick_tabs.uc.js` to load web URLs with a content principal (was the system principal) and restricted schemes to http/https; fixed the `DOMContentLoaded` listener typo in `userChromeDevtoolsSheetLoader.sys.mjs`; replaced the `toSource()`+`eval()` `OpenBrowserWindow` patch in `privateWindowHomepage.uc.js` with a delayed-startup observer; removed the `ChromeUtils.compileScript(...).executeInGlobal()` navigator-toolbox hack from `extendedStatusbar.uc.js`; and made `sidebarWidth.uc.js` wait for `SidebarController.sidebars`/`_box` (still present in FF157's reworked sidebar). CSS / stylesheet registration was left untouched by design
