## Relevant patterns for this project

- **`chromejs.uc.js`** — demonstrates how to register a custom address-bar pseudo-protocol (`chromejs:`) to execute privileged code from bookmarks/URL bar.
- **`moveButton`** — pattern for programmatically moving or cloning existing toolbar buttons/menus to custom locations via JavaScript.
- **`SidebarGestures`** — shows how to attach mouse-gesture handlers to sidebar web content.
- **`addmenuPlus`** — extensive examples of modifying native Firefox context/toolbar menus from userChrome.js.
- **`OpenLinkinNewTabwithRightClick.uc.js`** — minimal right-click-to-new-tab pattern.
- **`SimpleDragModY.uc.js`** — drag-direction gesture detection in chrome.
- **`userChrome.js` loader** — older loader variant with `@homepageURL` parsing; useful for understanding loader conventions pre-fx-autoconfig.

## Notes

- Most scripts target older Firefox versions (pre-Quantum and early Quantum).
- Repository is no longer maintained; scripts may require significant modernization for Firefox 150+.
- Chinese comments and documentation; useful as an idea index rather than direct copy-paste source.
- See linked Japanese/German/Chinese uc script wikis and related GitHub repos in the README for broader historical context.
