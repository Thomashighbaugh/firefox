## Design directive (explicit brief)

**Source design system:** Solid Glass (https://deeplethe.github.io/solid-glass/, https://github.com/deeplethe/solid-glass)  
**Task:** Port Solid Glass sensibilities to the Firefox userChrome/userContent setup:

1. Finish at the edge — rim (top light) + hairline (all-round) + shadow (underneath), never a gradient across the face.
2. Heavy, not airy — neutral grey faces; blur softens without boosting colour.
3. Depth is thickness — panel < card < popover. Thicker = more opaque.
4. One state — hovered, chosen and held-open all wear the same small pane of clear glass.

**Constraint (explicit):** Preserve current button sizing and especially tab animation+sizes+whatever as they are nearly perfect. Do not touch tab min/max-width, height, rainbow border animation, close-button behavior, button icon size (24px), padding (2px inner/outer), 83ms transform timing, or 0.7x active scale.

**Constraint (explicit):** Prefer existing color scheme; retain general monochromatic styling for most things (but not all). Ennumerated colors not white<--->black must be retained and added, not replaced. Specifically: all `--grey-*` and `--red-*` accent variables remain untouched.

**Constraint (explicit):** Button background should be a lighter gray than surrounding chrome (~#555555 equivalent / oklch(0.45 0 0)) for at-a-glance element identification, while keeping glass edge finish.
