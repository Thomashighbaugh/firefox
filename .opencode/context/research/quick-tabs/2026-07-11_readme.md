# Quick Tabs for Zen Browser

**Repo:** [Darsh-A/Quick-Tabs](https://github.com/Darsh-A/Quick-Tabs)
**Language:** JavaScript (userChrome.js)
**License:** MIT
**Stars:** 28

## Purpose

A userChrome.js script that opens links in floating tab containers (draggable, resizable popup browser windows) within the browser. Think picture-in-picture but for entire web pages.

## Features

- **Right-click → Open Quick Tab** from context menu
- **Drag-and-drop links** onto a floating taskbar
- **Renameable titles** (double-click, persists custom names)
- **Zen Command Palette integration** for scripted control
- **Quick Search integration** (coming soon)
- **Floating taskbar** at bottom-right to manage all open Quick Tabs
- **Back/Forward/Open-in-New-Tab** buttons in each container header
- **Minimize/Close** per container
- **Resize handle** bottom-right corner

## Installation

- Through [Sine](https://github.com/CosmoCreeper/Sine) (Extensions Manager, recommended)
- Manual: place `Quick_Tabs.uc.js` in `chrome/JS/` with [Fx-Autoconfig](https://github.com/MrOtherGuy/fx-autoconfig/)
- Add preferences from `preferences.json` to `about:config`
- **Clear Startup Cache** after installation

## Preferences

| Pref | Default | Description |
|------|---------|-------------|
| `extensions.quicktabs.theme` | "dark" | Theme: dark or light |
| `extensions.quicktabs.animations.enabled` | true | Smooth transitions |
| `extensions.quicktabs.closeSourceTab` | false | Close original tab on open |
| `extensions.quicktabs.taskbar.trigger` | "hover" | Show taskbar on hover or click |
| `extensions.quicktabs.context_menu.access_key` | "T" | Keyboard shortcut |
| `extensions.quicktabs.commandpalette.dynamic.enabled` | true | Dynamic commands for command palette |
| `extensions.quicktabs.initialPosition` | "center" | Initial screen position |
| `extensions.quicktabs.maxContainers` | 5 | Max floating containers |
| `extensions.quicktabs.defaultWidth` | 400 | Default width in px |
| `extensions.quicktabs.defaultHeight` | 500 | Default height in px |
| `extensions.quicktabs.taskbar.minWidth` | 200 | Min taskbar width in px |

## API Reference

Quick Tabs exposes `window.QuickTabs` with these methods:

- `QuickTabs.openQuickTab(url, title?)` — Create and open a floating container
- `QuickTabs.openQuickTabFromCurrent()` — Clone current tab into a floating container
- `QuickTabs.triggerOpenQuickTab(url, title?)` — Via browser command system
- `QuickTabs.triggerOpenQuickTabFromCurrent()` — Via browser command system
- `QuickTabs.getContainerInfo()` — Returns stats on all containers

Also exposes browser commands `cmd_zenOpenQuickTab` and `cmd_zenOpenQuickTabFromCurrent`.

## Architecture Notes

- Uses XUL `<browser>` elements with `type="content"` and `remote="true"`
- Fallback to XUL namespace method if standard method fails
- Loads content via `Services.io.newURI()` with system principal
- CSS injected dynamically via a `<style>` element
- Two theme variants: dark and light (CSS custom properties)
- Global state in `quickTabContainers` Map
- Taskbar at bottom-right with expand/collapse toggle
- Drag-to-move and drag-to-resize via mousedown/mousemove/mouseup on document
- Title monitoring via `DOMTitleChanged`, `load`, `pageshow`, `DOMContentLoaded`, `locationchange`, and a 2-second polling interval
- Back/forward navigation via multiple fallback methods
- Container limit enforced with notification toast
