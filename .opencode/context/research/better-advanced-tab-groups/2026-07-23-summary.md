# Better Advanced Tab Groups

Local reference copy of the **Better Advanced Tab Groups** userChrome.js customization set. It extends Firefox/Zen Browser's native `tab-group` element with a folder/group toggle, persistent state, custom color picking, and CSS theming.

## Files ingested

| File | Purpose | Lines |
|------|---------|-------|
| `better-tabgroups.uc.js` | Inject a "Switch to a Folder/Group" toggle into the tab-group editor panel and persist `groups` state per group ID | 228 |
| `tabgroup_colorpicker.uc.js` | Add a right-click color picker to the tab-group editor swatches to override the group color variables | 114 |
| `better-advanced-tab-groups.css` | CSS that styles `tab-group[groups="1"]` (folder) and `tab-group[groups="2"]` (group) with icons, arrows, transitions, and Zen-vertical-tabs support | 393 |

## `better-tabgroups.uc.js`

**Mechanism**
- Runs in browser chrome context; expects `Services`, `Ci`, `NetUtil`, and fx-autoconfig's `uc.js` environment.
- Stores one JSON state file per profile at `<ProfD>\chrome\savestate\tab-group-states.json`.
- On right-click inside a `<tab-group>`, initializes the custom `groups` attribute to `"2"` (group mode) and records the ID.
- Observes the tab-group editor panel and injects a toggle button immediately after `#tabGroupEditor_ungroupTabs`.
- Clicking the button flips `groups` between `"1"` (folder) and `"2"` (group), updates the button label, and saves the state.
- On startup, restores previously saved `groups` values for all matching `tab-group` elements.

**Key APIs / patterns**
- `Services.dirsvc.get("ProfD", Ci.nsIFile).path` for profile-relative paths.
- `Components.classes["@mozilla.org/file/local;1"]` + `nsIFile` for folder/file creation.
- `NetUtil.readInputStreamToString` for reading JSON state.
- `MutationObserver` on `.tab-group-editor-panel` to re-inject the button when the panel rebuilds.

**State schema**
```json
{
  "<tab-group-id>": 1,  // folder
  "<tab-group-id>": 2   // group
}
```

**Notable behaviors**
- Uses Windows-style backslash paths; may need normalization for cross-platform reuse.
- Toggle button styling is hard-coded inline and uses `var(--panel-item-hover-bgcolor)`.
- Script is guarded by `data-tab-group-toggler-initialized` on `<body>` to prevent double init.

## `tabgroup_colorpicker.uc.js`

**Mechanism**
- Watches `mainPopupSet` for a `.tab-group-editor-swatches` container.
- Injects a hidden `<input type="color">` inside the swatch container.
- Right-clicking any `.tab-group-editor-swatch` label opens the color picker seeded with the swatch's `--tabgroup-swatch-color`.
- On `change`, updates the CSS variables tied to the selected radio value:
  - `--tab-group-color-{value}`
  - `--tab-group-color-{value}-invert`
  - `--tab-group-color-{value}-pale`
- Simulates a radio `change` event so Firefox applies the selected color.

**Key APIs / patterns**
- `getComputedStyle(label).getPropertyValue('--tabgroup-swatch-color')`
- `document.documentElement.style.setProperty(...)`
- `MutationObserver` on `#mainPopupSet` with `childList` + `subtree`

**Notable behaviors**
- Updates all three color variants to the same picked value; no automatic light/dark derivation.
- Relies on the swatch label's `for` attribute mapping to a radio input ID.

## `better-advanced-tab-groups.css`

**Scope**
- Wrapped in `@media (-moz-bool-pref: "zen.tabs.vertical")`, so it only applies when Zen vertical tabs are enabled.
- Two primary modes driven by the `groups` attribute:
  - `tab-group[groups="1"]` — folder appearance with folder icon, expanded/collapsed states, optional range lines.
  - `tab-group[groups="2"]` — compact group appearance with small arrow chevron.

**Folder mode (`groups="1"`) highlights**
- Grid display, rounded container, background tint from `--tab-group-color-invert`.
- Optional border top/bottom via `tab.groups.borders`.
- Folder icon drawn with `mask-image` data-URIs; supports filled vs outline variants via `tab.groups.fill-folders` and `tab.groups.theme-folders`.
- Optional vertical tab-range lines controlled by `tab.groups.display-tab-range`.
- Optional collapse arrow controlled by `tab.groups.add-arrow`.
- Collapsed state clamps `max-height` and fades child `tab` elements.

**Group mode (`groups="2"`) highlights**
- Shorter label container (`20px`), gray label text, smaller right-pointing chevron.
- Collapsed state clamps to `20px` height.

**Shared features**
- Extensive use of CSS custom properties (`--tab-group-color`, `--tab-group-color-invert`, `--sidebar-text-color`, `--border-radius-medium`).
- Heavy `!important` usage typical of Firefox userChrome overrides.
- Data-URI inline SVG icons encoded both as base64 and as plain UTF-8 SVG.
- Nesting/ampersand syntax (`& tab`, `&:not([collapsed])`) supported by Firefox CSS parser.

## Integration notes for this project

- The `groups="1"|"2"` attribute pattern is the same convention used by the existing `advanced-tab-groups` research entry and by Firefox's native `tab-group` element.
- The state-persistence approach (JSON in `chrome/savestate/`) can be compared with `resources/second-sidebar/` persistence strategies if porting features into this theme.
- The color-picker logic is a lightweight alternative to full theme customization; could be adapted for sidebar panel accent colors.
- The CSS is Zen-specific; porting to this Higgs Boson theme would require reconciling variable names and removing Zen-only `@media` bool-prefs.
